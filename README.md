# Enzyme_classification - Using protein sequence embeddings

This repository contains a neural network–based enzyme classification model built on **precomputed protein embeddings** from UniProt.
The goal is to predict **enzyme classes (EC categories)** directly from protein sequence–derived representations.

## Overview

Protein sequences encode functional information, but learning directly from raw sequences is expensive.
This project instead uses **fixed-length protein embeddings** generated by UniProt using the **ProtT5 (prottrans_t5_xl_u50)** model.

These embeddings are treated as feature vectors and used to train a **multiclass neural network classifier** for enzyme class prediction.


## Data Source

### Protein Embeddings

* Source: UniProt protein embeddings
* Model used by UniProt: `prottrans_t5_xl_u50`
* Embedding type: **per-protein**
* Embedding dimension: **1024**
* Long sequences (>12k residues) are excluded by UniProt due to GPU constraints

More details:
[https://www.uniprot.org/help/downloads#embeddings](https://www.uniprot.org/help/downloads#embeddings)

### Labels

* Enzyme class labels were fetched from **UniProt annotations**
* Embeddings and enzyme classes were merged into a single dataset
* Final task: **7-class enzyme classification**



## Exploratory Analysis

Before modeling, dimensionality reduction was used to check whether enzyme classes naturally separate in embedding space.

### PCA

* Used to inspect global variance structure
* No strong class separation observed

### UMAP

* Applied to visualize potential non-linear clustering
* No clear enzyme-specific clusters detected

**Conclusion:**
The embeddings do not show obvious class separability via unsupervised methods, motivating supervised learning.



## Model Architecture

A fully connected neural network implemented in **PyTorch**:

* Input layer: `1024` (protein embedding size)
* Hidden layers:

  * 512
  * 256
  * 128
* Dropout: `0.5`
* Output layer: `7` (enzyme classes)
* Activation: ReLU
* Loss: Cross-Entropy
* Optimizer: Adam (`lr = 0.001`)



## Class Imbalance Handling

The dataset shows **enzyme class imbalance**, with dominant classes hurting performance.

To address this:

* **Oversampling** was applied to the training data
* This resulted in a noticeable improvement in classification accuracy (~12%)



## Training & Evaluation

* Train–test split performed before modeling
* Training:

  * 100 epochs
  * Batch training using `DataLoader`
* Evaluation:

  * Accuracy
  * Confusion matrix
  * Per-class performance inspection

Model evaluation is run both **before and after oversampling** to quantify its impact.
